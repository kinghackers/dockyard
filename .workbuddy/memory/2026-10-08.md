## dockyard 项目（Docker 管理器）
- 工程实际根目录：`E:/projects/mine/dockyard/src`（顶层 dockyard/ 仅有 src/ 子目录与一张 png）。
- 技术栈：Electron 33 + Vite 5 + React 18，多远程 Docker 管理桌面客户端（TCP/TLS/SSH/Unix Socket 连接、容器/镜像/网络/卷/Compose、实时事件、Darcula 风格）。
- 启动流程：`npm install` 已装（2026-10-08）；`npm run dev` 用 concurrently 同时拉 `vite` 与 `scripts/dev-electron.mjs`——后者 esbuild 将 `electron/main.ts`、`electron/preload.ts` 打包到 `dist-electron/`，等 http://127.0.0.1:5173 就绪后 spawn Electron 窗口。
- Vite 端口 5173；Electron 窗口由 dev-electron.mjs 拉起。
- 生产：构建 `npm run build` + 运行 `npm start`；Windows 打包 `npm run dist`（NSIS x64）。
